# 7b8k — FlaxOS 作者 · 专注墨水屏学习体验

**FlaxOS** 是一套面向墨水屏场景的轻量本地学习系统，以记忆卡学习为核心（类 Anki 体验的「知卡 FlaxCard」），辅以数独、番茄钟、本地音乐、网络电台等日常功能，深度适配电子墨水屏的显示特性。

<img src="logo-flat.png" width="18" height="18" alt="FlaxOS"> [**FlaxOS**](https://github.com/7b8k/FlaxOS) — 系统展示与实机演示

- 🧠 **知卡 FlaxCard**
  - Anki 牌组导入 · 选择题（单选/多选） · 挖空 · 翻页卡
  - **富文本卡面** — 图片 · LaTeX 公式 · 内联音频
- 🧩 **日常工具** — 数独（经典/杀手） · 番茄钟 · 联网天气 · 文件管理 · 计算器 · 日历
- 🎧 **音频** — 本地音乐 · 网络电台 · 蓝牙耳机
- 🔄 **互传** — LocalSend
